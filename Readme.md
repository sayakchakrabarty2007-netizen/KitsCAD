# KitsCAD

KitsCAD contains CAD and 3D-printable files for robotics and electronics projects.

## Projects

| Project | Formats |
|---|---|
| [DUSTBIN](DUSTBIN/) | STL |
| [FLOATING_LEVITATION](FLOATING_LEVITATION/) | STEP, STL |
| [HALL_SENSOR_DOOR](HALL_SENSOR_DOOR/) | STL |
| [JAMMER](JAMMER/) | STL |
| [LASER_SHOOTER](LASER_SHOOTER/) | STEP, STL |
| [LIFI](LIFI/) | STL |
| [SEISMOGRAPH](SEISMOGRAPH/) | STEP, STL |
| [SMART_SPECTACLES](SMART_SPECTACLES/) | STL |
| [SOLAR_TRACKER](SOLAR_TRACKER/) | STL |
| [WIRELESS_POWER_TRANSMISSION](WIRELESS_POWER_TRANSMISSION/) | STL |

## Usage

Open `.stl` files in a slicer for 3D printing or in compatible CAD software for editing. Open `.step` files in CAD applications that support STEP.
